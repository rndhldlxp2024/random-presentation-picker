# 🎯 랜덤 발표 순서 뽑기 (학급 추첨 시스템 - 8학급 지원)

교실 수업 및 수행평가에서 공정하고 재미있게 발표 순서를 추첨할 수 있는 **USB 포터블 웹 애플리케이션**입니다.

## ✨ 주요 기능

1. **8개 학급(1반~8반) 동시 관리 및 엑셀 붙여넣기**
   - 엑셀/한글/스프레드시트의 `[번호 / 이름]` 열을 복사(`Ctrl+C`)하여 그대로 붙여넣기(`Ctrl+V`)하면 자동으로 학생 명단이 등록됩니다.
2. **3가지 추첨 애니메이션 & 로또 원통 흔들기**
   - **🎱 로또볼 캡슐**: 2D 물리 엔진 기반 로또 원통 흔들기(`S` 키 또는 원통 클릭) 및 관성 충돌 애니메이션과 효과음 지원
   - **🎰 슬롯 릴**: 긴장감 넘치는 슬롯머신 릴 회전 연출
   - **🃏 카드 플립**: 3D 카드 뒤집기 연출
3. **차시별 수업 이어하기 & 지난 시간 발표완료 체크**
   - **`⏸️ 이어하기 저장`**: 수업 시간이 끝나 다음 시간에 이어서 발표해야 할 때, 현재까지 뽑은 순서를 USB 폴더 내 `roster_data.js`에 기록하여 다른 컴퓨터나 다음 수업 시간에도 그대로 이어서 추첨할 수 있습니다.
   - **`✅ 지난 시간 발표완료 체크` 모드**: 이미 발표를 마친 학생을 결석 처리하지 않고 클릭(또는 `Shift+클릭` / 우클릭)하여 발표 완료 순번에 즉시 추가할 수 있습니다.
4. **USB 휴대용 `뽑기 결과` 폴더 자동 생성 및 고화질 이미지(PNG) 저장**
   - 추첨 결과표를 Full HD(1920×1080) 고화질 PNG 이미지로 앱 폴더 내 **`뽑기 결과`** 폴더에 자동 저장합니다.
   - 클립보드 이미지 복사 및 엑셀/메신저용 텍스트 복사도 지원합니다.

## 🚀 실행 방법

- **방법 1 (일반 브라우저 실행)**: `index.html` 또는 `랜덤발표순서뽑기_단일실행파일.html`을 더블클릭하여 실행합니다.
- **방법 2 (USB 무중단 자동저장 실행기)**:
  - Windows: `USB_실행하기(자동폴더저장).bat` 실행
  - macOS: `USB_실행하기(자동폴더저장).command` 실행
